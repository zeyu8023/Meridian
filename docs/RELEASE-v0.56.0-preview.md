# Meridian 0.56.0-preview

Meridian 是 Xiaomi EV Mate 的非官方 Android 客户端。使用前必须先部署 [Ponyix/xiaomiev-mate](https://github.com/Ponyix/xiaomiev-mate)，并完成服务端账号与车辆配置。

## 本次更新（包含0.53–0.56的改进）

- 今日概况可打开所选日期的全部行程，支持分页读取和进入单次详情。
- 行程手记编辑入口改成轻薄图标胶囊，增加路况、天气、同行人员和行程感受点选；补充文字可选，保留旧手记与收藏状态。
- 统一输入框、默认字体层级、卡片主题材质、控件选择反馈和下拉菜单样式；图表颜色与AI推荐图标按内容含义匹配。
- 统计指标区分累计与周期，避免因同名分组遗漏数据；无有效详情的卡片取消展开入口。
- 调整AI导航球与导航标签，补充读屏语义，处理快速进退和手势状态变化时的动画取消逻辑。
- arm64 APK从57.87 MiB降至34.72 MiB，减少40.01%。三张大图无损WebP转码，移除一张未使用旧车图；全部视频原生库压缩打包，地图和动画保留。

## 下载与安装

- `Meridian-v0.56-preview.apk`：arm64-v8a，适用于多数现代Android手机。
- `Meridian-v0.56-armeabi-v7a-preview.apk`：32位ARM兼容版本。
- `SHA256SUMS.txt`：APK的SHA-256校验值。

维护者预览签名与既有预览版一致，可按系统提示覆盖安装；源码自行构建的签名可能不同。请保留自己的本机资料与备份。

## 体积优化的取舍

压缩的视频原生库由Android在安装时解压，因此安装后的存储占用按APK与解压库字节估算可能多约12.41 MiB，实际取决于系统。优化针对安装包下载和分享体积，不代表运行内存下降。没有降低图片分辨率、地图边界精度或删除视频库，也未启用未经真机回归的激进代码裁剪。
